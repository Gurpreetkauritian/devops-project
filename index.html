DevOps Mini Project

CI/CD Pipeline using Docker and GitHub Actions

About Project

This project demonstrates automated deployment of a static website using Docker and GitHub Actions. The project follows DevOps practices like Continuous Integration and Continuous Deployment.

Tools & Technologies Used

GitHub

Used for version control and repository management.

Docker

Used for containerizing the application.

GitHub Actions

Used to automate CI/CD workflow.

Workflow

  1. Developer writes code
  2. Code pushed to GitHub
  3. GitHub Actions triggers automatically
  4. Docker image builds
  5. Deployment process starts
